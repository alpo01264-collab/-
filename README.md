# Арена Терминал

Мобильный веб-терминал: оболочка `bash` на сервере, аккуратный тач-интерфейс под телефон
и кнопка **?** в правом верхнем углу со списком доступных команд.

## Запуск

```bash
npm start          # http://localhost:3000
PORT=8080 npm start
```

Зависимостей нет — нужен только Node.js 18+.

## Что умеет

- **Кнопка «?» в правом верхнем углу** открывает нижнюю панель со справочником команд:
  файлы, текст, система, сеть, git, разработка, помощь. Есть поиск и фильтр по категориям.
  Тап по команде подставляет её в строку ввода.
- **Команда `help`** делает то же самое, `clear` очищает экран.
- **Стриминг вывода**: результат приходит по мере выполнения, длинные команды не выглядят «зависшими».
- **`cd` запоминается** между командами — у каждой сессии (вкладки) своя рабочая папка.
- **Tab** — автодополнение команд и файлов с сервера, варианты показываются чипами.
- **Ctrl C** — прерывание выполнения, **↑ / ↓** — история команд (хранится в `localStorage`).
- Учёт кода возврата, таймаут на команду (по умолчанию 120 с), автоскролл и кнопка «вниз».
- Мобильная вёрстка: `100dvh`, safe-area для «чела» iPhone, поле ввода над экранной клавиатурой,
  тактильная отдача, PWA-манифест (можно добавить на домашний экран).

## Структура

```
server.js               HTTP-сервер, выполнение команд, стриминг, автодополнение
public/index.html       разметка интерфейса
public/styles.css       мобильные стили
public/app.js           логика терминала и панели «?»
public/commands.js      справочник команд (правится в одном месте)
public/manifest.webmanifest, icon.svg
```

## API

| Метод | Путь | Описание |
| --- | --- | --- |
| `GET` | `/api/info` | пользователь, хост, домашняя папка, платформа |
| `POST` | `/api/exec` | `{ sessionId, command }` → поток SSE: `start`, `out`, `end` |
| `POST` | `/api/complete` | `{ sessionId, prefix }` → `{ items: [...] }` |
| `GET` | `/healthz` | проверка живости |

## Важно про безопасность

Сервер выполняет любые команды от имени своего пользователя, без авторизации.
Это инструмент для личного/локального использования и доверенной сети — не выставляйте
его в открытый интернет. Для удалённого доступа ставьте перед ним reverse-proxy
с аутентификацией и TLS.

Интерактивные программы (`vim`, `nano`, `top`, `ssh`) не поддерживаются: нет PTY.
Используйте неинтерактивные аналоги (`cat`, `head`, `ps aux`) и флаги вроде `-y`, `--no-pager`.
